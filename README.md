# Water-Tanker-Booking-Records# Water Tanker Booking System

## About the Project
The Water Tanker Booking System is a web application that allows users to book water tankers by entering their name, area, booking date, and tanker size.

## Technologies Used
- Java
- JSP (JavaServer Pages)
- JDBC
- MySQL
- HTML
- CSS
- Apache Tomcat
- Maven

## Features
- Book a water tanker.
- Store booking details in MySQL.
- Display recent bookings.
- Prevent duplicate bookings.

## Database
Database Name: `watertankdb1`

Table Name: `tank`

## How to Run
1. Clone or download the repository.
2. Open the project in your IDE.
3. Configure the MySQL database.
4. Update the database username and password.
5. Run the project on Apache Tomcat.
6. Open the application in your browser.
